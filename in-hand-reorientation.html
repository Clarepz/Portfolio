In-hand reorientation

Context
Real-World Robotics course (HS26), ETH Zurich
Team
Team project
Task
Rotate a cube in a robotic hand with a learned policy
Tools
Isaac Lab, reinforcement learning
Hardware
Robotic hand (ORCA v1)
Score
Number of successes: times the cube reaches the next target angle within a given time

Images

Train a reinforcement-learning policy to rotate a cube in a robotic hand. It was the first task of the Real-World Robotics course at ETH Zurich (HS26), which we did as a team, and the policy has to work on a real hand, not only in simulation.

The task came in four parts: setting up the RL environment in Isaac Lab, defining the reward function and training the policy, tracking the cube's rotation angle in the real world (the course provided that tracking), and applying sim2real techniques so the policy holds up on the real hand. It is scored by the number of successes, meaning how many times the cube reaches the next target angle within a given time.
